## Five-minute orientation

1. Open authoritative worktree: `.worktrees/project-atlas-authoritative`.
2. Confirm branch: `cursor/project-atlas-rc1`.
3. Read `PROJECT_ATLAS/CONTINUATION/STARTUP_SEQUENCE.md`.
4. Read `PROJECT_ATLAS/CURRENT_STATE.md`.
5. Read `PROJECT_ATLAS/CONTINUATION/ACTIVE_SPRINT.md`.
6. Read `PROJECT_ATLAS/NEXT_ACTIONS.md`.
7. Read the assigned Track, Sprint, Agent, and Decision pages.

## Safety checks

- Use an isolated worktree for any proposed change.
- Do not edit another agent’s workspace.
- Do not merge, commit, deploy, or contact external systems without explicit authorization.
- Treat external dependencies as mocked.
- Keep Production frozen.
- Do not start Sprint 5 without owner assignment.

## Stop condition

When assigned work is complete, produce a handoff with changed documentation paths, assumptions, risks, debt, QA evidence, and recommended next sprint. Stop and await QA validation.
