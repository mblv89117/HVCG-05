# HVCG Client Portal Sprint 1 — README

Multi-client secure engagement workspace MVP.

## Quick start

```bash
cd apps/hvcg-client-portal
npm install --cache /tmp/npm-cache-hvcg-portal
npm run dev
```

Open http://localhost:5174
