# USER GUIDE — HVCG Command Center

Audience: Operations Assistant, Project Managers, Analysts. Training target: ≤2 hours.

## What this system is

Your daily tool for clients, projects, tasks, documents, deliverables, meetings, and decisions. Files live in SharePoint; you usually work in the **HVCG Project Command Center** app.

## Sign in

Use your HVCG Microsoft 365 account. MFA required.

## Home screens

- **Operations Home** — today’s work metrics and shortcuts  
- **Executive Home** (Manny) — only items needing his decision  

## Clients

1. Open **Clients**  
2. Search by name or code  
3. Open a client to see health, projects, documents, meetings  

### Activate a new client

1. Quick Create → Client  
2. Fill legal name, ClientCode, owners, fees  
3. Set stage to **Active Client**  
4. Wait a few minutes for workspace + checklist to appear  
5. If something is missing, tell Admin (do not create random folders by hand)

## Tasks

- **My Tasks** shows your work  
- Update status as you go  
- Put blockers in the Blockers field — do not leave silent  

## Document requests

- Track what the client still owes  
- Mark Received → In Review → Accepted / Rejected  
- The system reminds clients on a schedule; escalate to PM only when stuck  

## Deliverables

- Move status Drafting → Internal Review when ready  
- Approvers get notified  
- Store files in the client library under **19 - Deliverables**

## Meetings

- Log meetings with the meeting template fields  
- Capture decisions and action items  
- Do **not** send major client emails until approved if your team uses the approval flag  

## Decisions & risks

- Log decisions early  
- If Manny must decide, set **Requires executive attention** and pick a reason  
- Do not mark routine items as executive  

## What you should not do

- Do not share client libraries with anonymous links  
- Do not upload real client data into Dev  
- Do not invent parallel trackers in personal Excel as the master system  

## Need help?

Ask Ops Manager / Admin. See Admin Guide for access issues.
