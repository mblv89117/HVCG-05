# SOP — External Document Sharing

**Owner:** Administrator / Operations Manager  

## Policy

- No anonymous links on HVCG-Clients.  
- Specific people only; expiration ≤30 days.  
- Log an Approval of type ExternalShare before sending.  

## Steps

1. Confirm business need and named recipients.  
2. Create `HVCG_Approvals` item; obtain Approver decision.  
3. Share only the required folder/file.  
4. File share confirmation under `21 - Communications`.  
5. At engagement closeout, revoke access (see Closeout template).
