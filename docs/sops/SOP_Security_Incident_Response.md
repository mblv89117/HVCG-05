# SOP — Security Incident Response (Summary)

1. **Contain** — disable user or revoke links immediately.  
2. **Preserve** — do not delete audit evidence.  
3. **Notify** — Owner (Manny) and Administrator.  
4. **Investigate** — Purview audit + Automation/Audit lists.  
5. **Remediate** — password reset, access review, client notice if required by counsel.  
6. **Record** — HVCG_Issues type Security + post-incident notes.  
7. **Improve** — update SOP / DLP as needed.
