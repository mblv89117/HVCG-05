# SOP — Client Onboarding

**Owner:** Operations Manager  
**System:** HVCG Command Center  

## When to use

New client is ready to begin paid work.

## Steps

1. Create or verify **Client** record (legal name, ClientCode, owners, fees, capital fields).  
2. Confirm engagement letter stored (or pending with dated task).  
3. Set **ClientStage = Active Client**.  
4. Verify within 15 minutes:  
   - SharePoint library URL on client  
   - Onboarding project + tasks  
   - Document requests  
   - Setup/retainer financial milestones  
5. Confirm kickoff scheduled.  
6. Do not notify Manny unless an executive escalation reason applies.

## Failure recovery

If automation fails, notify Admin; run workspace + template scripts; log in AutomationLogs manually if needed.
