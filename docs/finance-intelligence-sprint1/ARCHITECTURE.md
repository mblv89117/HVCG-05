# Architecture

See Atlas mirror: `PROJECT_ATLAS/Architecture/FinanceIntelligenceSprint1.md`

Finance Intelligence separates:

1. **Provenance** — source catalog + evidence kinds  
2. **Measurement** — KPI objects with mandatory metadata  
3. **Interpretation** — AI observations (always human-reviewed)  
4. **Valuation** — indicative EV models  
5. **Access** — role × route × org awareness  

HVCG demo numbers derive from Finance Operations Sprint 1 mock store. CCB exposes structure without inventing dollars.
