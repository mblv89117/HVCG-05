## One-paragraph summary

HVCG Finance Operations Sprint 1 is a Vite + React 19 mock financial operating system with pure engines for invoices, billing (MRR/ARR), proposal pricing, forecast, and collections; seven role-gated dashboards; and configuration-driven stubs for Stripe, QuickBooks, Mercury, Square, Power BI, and Microsoft Lists — with no live credentials and no changes to Revenue OS, Client Portal, Executive Command Center, CRM schema, Track 1, or Production.
