# TRAINING PLAN

| Audience | Duration | Materials |
|----------|----------|-----------|
| Ops Assistant | 2 hours | USER_GUIDE, live Dev walkthrough with sample client SRM01 |

1. Create client → activate → verify workspace  
2. Accept/reject a document request  
3. Move deliverable to Internal Review  
4. Create executive decision vs routine task (contrast)  
5. Offboard a test contractor from one client group
