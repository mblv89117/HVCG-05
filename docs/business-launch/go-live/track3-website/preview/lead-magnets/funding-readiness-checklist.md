## Checklist sections

### 1. Capital intent clarity

- [ ] Stated capital purpose (growth, refinance, acquisition, working capital)
- [ ] Target amount band documented (internal range)
- [ ] Timeline window (0–3 / 3–6 / 6–12 / 12+ months)
- [ ] Decision maker identified and reachable

### 2. Financial records

- [ ] Trailing 12-month revenue traceable
- [ ] P&L current within 45 days
- [ ] Balance sheet current within 45 days
- [ ] Bank statements (3–6 months) organized
- [ ] Tax returns (2 years) accessible
- [ ] AR/AP aging available

### 3. Debt & obligations

- [ ] Debt schedule with rates, covenants, maturity
- [ ] Off-balance-sheet obligations listed
- [ ] Personal guarantees documented
- [ ] UCC / lien awareness

### 4. Operations narrative

- [ ] One-page business model summary
- [ ] Customer concentration noted (no client names on public version)
- [ ] Key contracts / leases indexed
- [ ] Management bios for lender pack

### 5. Collateral & security (if debt path)

- [ ] Asset list with rough values
- [ ] Insurance certificates current
- [ ] Real estate / equipment docs indexed

### 6. Governance & compliance

- [ ] Entity docs (articles, operating agreement)
- [ ] Cap table / ownership chart
- [ ] Licenses and permits current
- [ ] No active litigation undisclosed

### 7. Enterprise value drivers (EVA themes)

- [ ] Revenue quality and recurrence understood
- [ ] Margin drivers identified
- [ ] Growth investments tied to capital ask
- [ ] Known value blockers listed

### 8. Next steps

- [ ] Complete Enterprise Value Assessment (free)
- [ ] Complete Capital Readiness Assessment
- [ ] Book Appointment when qualified
