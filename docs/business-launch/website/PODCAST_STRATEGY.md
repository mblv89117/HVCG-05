## Format

| Element | Spec |
|---------|------|
| Length | 25–40 minutes |
| Frequency | Monthly (staging target) |
| Host | HVCG principal / invited operator-grade guests |
| Guests | No client logos; generic titles only until approved |
| Distribution | Embed on `/podcast`; RSS when live |

**No paid hosting purchase for staging** — use M365 Stream or tenant-default if available.
