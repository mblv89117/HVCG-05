# CONVERSION_PATH

**Brand:** High Value Capital Group LLC  
**As of:** 2026-07-15  
**Canonical funnel:** EVA → Capital Readiness → Strategy Call → Proposal  
**Environment:** Staging only — no live outbound without approval

## Path overview

```
Traffic (staging site)
  → Free EVA
  → Capital Readiness Assessment
  → Preliminary report (concept / draft template)
  → Qualification score
  → Service path + pricing range (rates TBD BL-P1)
  → Book Strategy Call
  → Proposal
  → Agreement → Payment → Onboarding (post-site; HVCG OS)
```

Website owns steps through **Book Strategy Call**. Proposal+ lives in CRM / OS.

---

## Stage detail

### 1. Entry → Free EVA

| Item | Spec |
|------|------|
| Primary entry CTAs | Home, Services, Process, Resources → **Start free EVA** |
| Mechanism | Microsoft Forms (or Power Apps) on `/assessments/eva` |
| Capture | Name, email, company, role, capital intent, high-level financial self-inputs |
| System write | Power Automate → Dev `HVCG_Leads` (+ assessment fields) |
| Success state | “Next: Capital Readiness” with continue CTA |
| Disclosures | Link Disclaimer; no valuation/funding guarantee |

### 2. EVA → Capital Readiness

| Item | Spec |
|------|------|
| Trigger | EVA complete (or skip discouraged; soft prompt) |
| Page | `/assessments/capital-readiness` |
| Inputs | Debt/collateral/timeline/docs maturity/capital type |
| Output | Readiness score + gap themes (not a financing decision) |
| System write | Update Lead / related assessment list in Dev |
| Branch | High readiness → encourage Strategy Call; low → Resources + optional call |

### 3. Preliminary report

| Item | Spec |
|------|------|
| Staging | Template only; **no automated client email** until approved |
| Content | EVA themes + readiness gaps + suggested service path |
| CTA | Book Strategy Call |
| Forbidden | Client comparisons, logos, promised capital amounts |

### 4. Qualification score

| Item | Spec |
|------|------|
| Inputs | See `IDEAL_CLIENT_PROFILE.md` |
| Outcomes | Qualified / Nurture / Disqualified |
| Site behavior | Qualified → Book Call emphasized; else FAQ/Resources |
| CRM | Stage field on Lead / Opportunity when promoted |

### 5. Service path + pricing range

| Item | Spec |
|------|------|
| Page support | `/pricing`, service detail pages |
| Logic | Map interests → Capital Advisory / Fractional CFO / Business Growth (± combos) |
| Dollars | **TBD** until `BL-P1`; show drivers and “range pending confirmation” |
| CTA | Book Strategy Call |

### 6. Strategy Call

| Item | Spec |
|------|------|
| Page | `/book-strategy-call` |
| Mechanism | Microsoft Bookings or request form → `HVCG_DiscoveryCalls` |
| Pre-req | Prefer EVA + Readiness complete; allow exception with reason |
| Confirm | Internal calendar only in staging |

### 7. Proposal (off-site / CRM)

| Item | Spec |
|------|------|
| Owner | CRM / sales process on HVCG OS |
| Site role | “What happens after the call” on Process + FAQ |
| Artifact | `HVCG_Proposals` — not generated by public site in V1 |
