# Phase 4B-1 Folder Recommendation Policy

Aligns to HVCG client workspace folder standards (draft recommendation only).

## Response

- `proposedClient`
- `proposedWorkspace`
- `proposedFolderPath` (e.g. client → Financial / Legal / Operating / Correspondence by type)
- `confidence`
- `alternativePaths`
- `reason`
- `missingContext`
- `fileMoved: false` **always**

No copy or move is performed on approve or any other decision.
