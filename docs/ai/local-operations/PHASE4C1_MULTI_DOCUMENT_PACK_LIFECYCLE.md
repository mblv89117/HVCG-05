# Phase 4C-1 Multi-Document Pack Lifecycle

- Packs are Manny-created from manually selected staged reviews only.
- Limits: existing `DEFAULT_MULTI_DOC_MAX_FILES` / `DEFAULT_MULTI_DOC_MAX_BYTES`.
- Persisted: members, relationships, conflicts, missing items, recommendation, decision package, corrections, audit.
- No automatic folder or external-system access.
- Pack decisions are local drafts with no side effects.
