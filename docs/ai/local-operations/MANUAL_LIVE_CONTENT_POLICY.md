# Manual Live-Content Policy

- Sources: pasted text, uploaded docs, meeting notes, copied emails, client summaries — **manual only**
- Forbidden: auto-read Outlook, OneDrive, SharePoint, Dataverse, Gmail, calendars, live client connectors
- Every pack requires: Manny initiation, source confirmation, client ID/label, sensitivity, redaction preview, explicit process approval, audit correlation ID
- Non-synthetic content requires `ownerApprovedLiveContent=true`
- Labels: `TEST — DO NOT CONTACT` / `TEST — SYNTHETIC DATA` / `TEST — SYNTHETIC AI OUTPUT — DO NOT SEND`
