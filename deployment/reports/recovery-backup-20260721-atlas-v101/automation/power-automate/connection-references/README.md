# Connection References

Production connections must be created under the **HVCG Ops Automation** service account:

| Reference name | Connector |
|----------------|-----------|
| HVCG_Conn_SharePoint | SharePoint |
| HVCG_Conn_Outlook | Office 365 Outlook |
| HVCG_Conn_Teams | Microsoft Teams |
| HVCG_Conn_Approvals | Approvals (if used) |

Never use the owner personal account as the flow owner in production.
