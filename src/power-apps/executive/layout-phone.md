# Executive Command Center — Phone Layout

**Screen:** scrHomeExec  
**Breakpoint:** width < 640

## Stack (top → bottom)

1. **Header** — HVCG OS · Cash MTD/YTD toggle · Refresh  
2. **KPI scroll** — horizontal `cmpExecKpiTile` gallery (Pipeline, MRR, AR, Capital first)  
3. **Attention** — Clients Needs Attention (max 5)  
4. **My work** — Decisions → Approvals → Risks → My tasks → Meetings  
5. **Capital / proposals** — collapsed sections, expand on tap  

## Rules

- One job per section  
- No nested horizontal scrolls except KPI strip  
- Deep-link rows to detail screens; avoid modal stacks deeper than 1  
- Hide BI embeds on phone (link to Power BI mobile app instead)
